# 역할별 시작 화면과 오늘 할 일

ERP 아이콘으로 처음 진입하면 담당 업무 시작 화면을 표시한다. URL에 업무나 문서가 지정되어 있으면 해당 화면을 유지한다. 대시보드 메뉴의 `오늘 할 일`은 모든 ERP 접근자가 이용하고 `월별 대시보드`는 기존 ADMIN 권한을 유지한다.

| 담당 업무 | 우선 바로가기 | 오늘 할 일 범위 |
| --- | --- | --- |
| ADMIN | 입고, 출고, 출고 문서, 월별 현황 | 회사 승인 대기, 미수 회수·수금 배분, 차용 반환, 원가 확정, 정정 명세표, 월마감 |
| Sub_ADMIN ERP관리자 | 입고, 출고, 원장·정정, 창고 이동 | 본인 승인 요청, 배정 마감 |
| 입출고 전체 | 입고, 출고, 창고 이동, 재고 | 본인 승인 요청, 배정 마감 |
| 입고 담당 | 입고, 재고, 원장 | 본인 승인 요청, 배정 마감 |
| 출고 담당 | 출고, 재고, 원장 | 본인 승인 요청, 배정 마감 |
| 조회 전용 | 재고, 원장 | 본인 승인 요청, 배정 마감 |

## 표시와 이동

- 기준일은 서버의 한국시간 날짜다. 기한 경과·오늘 예정 업무를 먼저 보여주며 향후 예정도 구분한다. 승인 요청일, 차용일, 원본 기준일을 임의의 연체 기한으로 취급하지 않는다.
- 승인 완료·반려 요청은 대기에서 빠진다. 일반 담당자는 본인 요청만 조회하고 승인·반려 버튼은 ADMIN만 사용한다. 특정 요청 링크는 해당 ID를 별도로 조회하므로 목록 첫 페이지 밖 요청도 찾을 수 있다.
- 미수 회수는 기존 출고·반품·수금·배분 원장에서 오늘 기준 잔액을 계산한다. 출고 문서 잔액과 거래처 미배분 수금을 함께 표시한다. 미배분 수금이 있으면 먼저 기존 수금을 확인하도록 안내하며 이를 새 매출이나 새 수금으로 기록하지 않는다. 통화가 다른 금액은 합산하지 않는다. 출고 문서 상세로 이동하여 처리한다.
- 차용 반환은 양수 미반환 수량을 표시하고 해당 차용 건의 현물 반환 입력으로 연결한다. 목록 진입만으로 반환을 등록하지 않는다. 실제 회사 소유 재고와 최신 수량은 기존 미리보기·확정에서 다시 검증한다.
- 원가 대기는 원본 수량·단위를 표시하고 해당 품목의 원가 확정 화면으로 연결한다. 수량 공란, 사용 중지, 미래 원본 기준일을 숨기거나 0원 자산으로 바꾸지 않는다.
- 미발행 정정 거래명세표는 원문서를 대체하는 초안만 표시한다. 특정 초안 ID로 바로 열며 일반 초안을 정정 대기로 집계하지 않는다. 발행·취소 후에는 대기에서 빠진다.
- 마감은 기존 담당자 배정·체크리스트와 같은 기준을 사용한다. 담당자가 완료 보고한 항목은 본인 미보고 업무에서 빠지고 ADMIN 최종 확인·마감은 계속 남는다. 대상 월을 직접 연다.

## 조회와 권한

`manageErpControl.workQueue`는 읽기 전용이다. 현재 회사·ERP 권한을 최초 조회, 각 항목 트랜잭션, 최종 응답 전에 재검사한다. ADMIN이 아닌 요청은 재무·보관·원가 컬렉션을 읽지 않으며 해당 항목 자체를 응답에서 제외한다. 다른 사람의 승인 요청이나 배정되지 않은 마감 일정은 제공하지 않는다.

각 업무 조회 오류를 다른 업무와 분리한다. 실패한 항목은 `확인 필요`로 표시하고 0건으로 처리하지 않는다. 승인·차용·원가·정정 명세표 대기는 최대 100건까지 집계하며 초과 시 `100+`를 표시한다. 항목별 상세는 10개까지 보여주고 전체 업무 화면으로 연결한다. 미수 원장은 기존 20,000행 한도를 사용하며 초과 시 일부 합계를 제공하지 않는다.

시작 화면 진입·수동 새로고침으로 조회한다. 1분 이상 지난 후 창을 다시 볼 때 갱신하며 금융 원장을 상시 폴링하지 않는다. 사용자의 미저장 입력을 자동으로 변경하거나 거래를 확정하지 않는다. 기존 회사 격리, ERP관리자의 직접 정정 범위, ADMIN 승인, 변경 이력과 월마감 잠금을 유지한다.

개인 승인 대기를 위한 `erpApprovals`의 `requestedBy + status + createdAt(오름차순)` 인덱스와 `erpIssuedDocuments`의 `status + kind + replacesId` 인덱스가 필요하다. 새로운 컬렉션·회사 자료 이관·은행 연동은 없다.

현재 **3-5 사용성 검증과 운영 반영**에서 입력 오류 복구·수금 입력 개선을 구현했다. 사용자가 지정한 에스지앤플래닛의 실제 담당자 측정은 개선 배포 후 진행하며 [측정 기록표](erp-usability.md)를 사용한다. 자동 회귀 통과만으로 실제 사용자 시간 감소를 달성했다고 간주하지 않는다.
