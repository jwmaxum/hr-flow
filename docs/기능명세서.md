# HR Flow 기능요약 설명서

업데이트 기준: 2026-10-28

랜딩페이지와 앱의 현재 역할 표시를 기준으로 회사 가입, 역할별 관리 범위와 업무 처리 절차를 설명합니다.

## 기능 한눈에 보기

| 기능 | 제공 내용 |
| --- | --- |
| 회사 가입·조직 관리 | 회사를 등록하고 직원 계정과 본부·팀을 구성합니다. 회사 대표자와 추가 관리자 구분 · 직원 ID·임시 비밀번호 발급 · 소속 배정·팀장·본부장 지정 |
| 직원 인사 관리 | 인사카드와 연차, 계정 상태를 회사 단위로 관리합니다. 주민등록번호·주소·연락처 관리 · 추가 연차 부여·사용 현황 확인 · 업무정지·퇴사·비밀번호 초기화 |
| 근태·휴가 | 본인의 출퇴근을 기록하고 휴가 신청과 승인 상태를 확인합니다. 근태 기록·타임라인·월별 달력 · 입사일 기준 연차·잔여 일수 · 연차·반차 신청 및 본인 내역 |
| 결재·지출 관리 | 본부 1차 결재와 회사 최종 승인을 구분하고 비용을 조회합니다. 휴가·지출은 ADMIN 직접 최종 승인 가능 · 서류 결재 대기 건수 표시 · 승인 지출 CSV·영수증 ZIP 다운로드 |
| 공지 게시판 | 회사 공지와 첨부자료를 구성원에게 전달합니다. 관리자·부관리자 공지 작성 · 작성자의 본인 글 수정 · ADMIN의 회사 공지 수정·삭제 |
| 급여 예상액 계산 | 연봉·월급과 공제 정보를 입력해 월 예상 실수령액을 계산합니다. 2026년 3월 적용 근로소득 간이세액표 · 가족·자녀·비과세액 반영 · 소득세·지방소득세·보험 공제 구분 |
| 공문·재직·경력증명서 | 회사 템플릿으로 작성·결재한 서류를 비공개 PDF로 보관합니다. 로고·대표자·인감·mm 크기 설정 · 자동 문서번호·결재·개정 이력 · 기간 조회·PDF 다운로드·관리자 삭제 |
| 기안·업무보고 | 내부 기안 결재와 일일·주간 업무보고 확인을 한 메뉴에서 처리합니다. 본부·연월별 기안번호와 선택 결재 · 팀장·본부장 업무보고 확인 · 기간 조회·첨부자료·확인자 PDF 보관 |
| 권한·시스템 설정 | 회사별 접근 범위와 로그인·도메인·문서 설정을 관리합니다. 플랫폼과 가입 회사의 관리 범위 구분 · 직원 최초 로그인 비밀번호 변경 · 민감한 관리 작업의 비밀번호 재확인 |

## 처음 시작하는 순서

1. 회사·조직의 한글명과 영문명, 가입자 정보를 입력하고 이메일 인증을 완료합니다.
2. 회사 대표자가 본부·팀을 만들고 추가 관리자와 부관리자, 팀장·본부장을 지정합니다.
3. 직원 계정을 등록하고 로그인 ID와 임시 비밀번호를 개별 전달합니다. 직원은 첫 로그인에서 비밀번호를 변경합니다.
4. 인사카드·입사일·연차와 급여 정보를 확인하고, 휴가·지출의 결재 담당을 정합니다.
5. 회사 서류 템플릿을 저장한 뒤 공문·증명서를 작성·승인하고 서버에 저장된 PDF를 다운로드합니다.

## 역할과 메뉴 권한

| 앱 표시명 | 명칭 | 관리 범위 | 담당 업무 |
| --- | --- | --- | --- |
| SYSTEM_ADMIN | 플랫폼 운영자 | 관리 범위: 플랫폼 운영 | 가입 회사와 회사 대표자, 구독 등 플랫폼 운영을 관리하는 운영자입니다. |
| SUPER_ADMIN | 회사 대표 가입자 | 관리 범위: 소속 회사 · 회사 소유자 | 각 회사의 최초 가입자이며 직원과 추가 관리자를 등록해 회사 운영을 관리합니다. |

## 1. 회사·조직 가입과 로그인 ID

대상: 회사 대표 가입자 · 회사 관리자

회원가입은 회사 또는 조직 단위로 진행합니다. 회사명과 가입자 정보를 등록한 뒤 직원 계정을 추가합니다.

### 처리 순서

1. 가입 화면에서 회사·조직의 한글 이름, 영문 이름과 가입자 정보를 입력합니다.
2. 가입 이메일의 인증을 완료하고 회사 등록을 마칩니다. 최초 가입자는 회사 소유자로 구분됩니다.
3. 회사에서 사용할 로그인 주소를 정합니다. 예: 영문명 Biz Peer인 회사에서 hong을 입력하면 hong@bizpeer.com으로 자동완성됩니다. 생성 전에 화면에 표시된 최종 주소를 확인합니다.
4. 시스템 설정에서 회사 도메인을 변경하려면 관리자 비밀번호와 새 도메인의 이메일 인증을 확인합니다.
5. 기존 직원 계정을 동기화한 경우 변경된 로그인 주소를 직원에게 안내하고 실패한 항목은 다시 확인합니다.

### 기능과 권한

- 직원 로그인 ID는 이메일 주소 형식입니다. 회사 도메인은 로그인 주소 체계이며 이 기능만으로 실제 메일함이 만들어지지는 않습니다.
- 직원 ID만 입력하면 영문회사명 기반 .com 주소를 사용합니다. 다른 도메인을 사용하려면 hong@custom.example처럼 전체 로그인 주소를 입력할 수 있습니다.
- 회사는 서버가 발급하는 고유 식별자로 구분됩니다. 회사 이름이나 로그인 도메인을 바꾸는 일과 다른 회사로 소속을 옮기는 일은 다릅니다.

### 확인할 사항

- 자동완성은 영문회사명을 소문자로 바꾸고 공백을 제거한 .com 주소입니다. 영문명에 도메인으로 쓸 수 없는 문자가 있으면 전체 로그인 주소를 입력하세요. 기존 직원의 로그인 주소는 자동 변경하지 않습니다.
- 시스템 도메인 저장·기존 계정 동기화와 신규 ID 자동완성은 구분해 확인하세요. 도메인 변경 후 생성하는 계정도 최종 로그인 주소를 확인해야 합니다.

## 2. 역할과 관리 범위

대상: 모든 사용자

플랫폼 운영, 회사 대표자, 추가 관리자, 부관리자와 직원의 업무 범위를 나눕니다.

### 처리 순서

1. 플랫폼 운영자는 가입 회사와 회사 대표자, 구독 등 서비스 운영을 관리합니다.
2. 회사 대표 가입자는 조직을 구성하고 직원을 생성하며 추가 회사 관리자에게 권한을 부여합니다.
3. 회사 관리자들은 같은 회사의 조직·인사·급여·설정과 최종 결재를 관리합니다.
4. 부관리자는 소속 본부 범위에서 근태와 휴가·지출의 1차 결재를 담당합니다.
5. 직원은 본인 업무와 신청 내역을 확인하고, 문서에 지정된 결재자는 해당 서류의 결재에 참여합니다.

### 기능과 권한

- 역할과 메뉴 접근은 위 권한표를 기준으로 확인합니다. 회사 관리자라도 다른 회사의 직원이나 문서를 관리하는 권한을 갖지는 않습니다.
- 서류 최종 승인 위임은 회사 관리자가 본부가 배정된 부관리자에게 별도로 설정합니다. 템플릿 변경·발행본 삭제 권한까지 위임되는 것은 아닙니다.

## 3. 조직 관리: 본부·팀·직원 등록

대상: 회사 대표 가입자 · 회사 관리자

회사 → 본부 → 팀 구조를 만들고 직원의 계정·역할·소속을 배정합니다.

### 처리 순서

1. 조직 관리에서 본부를 만든 뒤 각 본부 아래 팀을 생성합니다.
2. 직원 이름, 로그인 ID, 입사일과 소속 팀을 입력해 신규 계정을 등록합니다.
3. 발급된 로그인 ID와 임시 비밀번호를 해당 직원에게 개별 전달합니다. 직원은 최초 로그인 후 새 비밀번호로 변경해야 합니다.
4. 회사 운영에 필요한 직원에게 관리자 또는 부관리자 권한을 부여합니다.
5. 본부장과 팀장을 지정하고, 소속 이동이 생기면 팀·본부 배정과 변경 이력을 확인합니다.

### 기능과 권한

- 아이디 중복 또는 다른 회사 소속의 팀을 선택한 경우 등록이 거절될 수 있습니다. 화면에 확정된 로그인 주소를 확인한 뒤 전달하세요.
- 팀장·본부장 지정은 서류 결재라인 구성에 사용됩니다. 부관리자 역할의 휴가·지출 결재 범위는 현재 배정된 본부입니다.
- 직원에게 공유할 임시 비밀번호는 관리 화면의 등록 결과를 사용하며 공개 설명서에는 기재하지 않습니다.

## 4. 인사 관리: 인사카드·연차·계정 상태

대상: 회사 대표 가입자 · 회사 관리자

등록한 직원의 인사 정보를 보완하고 재직 상태, 연차와 비밀번호를 관리합니다.

### 처리 순서

1. 인사 관리에서 직원을 선택하고 주민등록번호, 주소, 연락처, 개인 이메일 등 필요한 인사카드를 작성합니다.
2. 입사일 기준 연차와 사용 일수를 확인하고 포상·특별 사유가 있으면 추가 연차를 입력합니다.
3. 업무를 중단하거나 퇴사한 계정은 정지 처리해 접근을 차단합니다. 기존 업무 기록을 남기는 처리와 계정 삭제를 구분합니다.
4. 업무 복귀가 승인된 직원은 정지를 해제하고 소속과 권한을 다시 확인합니다.
5. 비밀번호 초기화나 계정·기록 삭제는 관리자 비밀번호를 확인한 뒤 진행하고, 결과와 삭제 범위를 확인합니다.

### 기능과 권한

- 부관리자에게는 본부 업무에 필요한 최소 직원 정보가 제공됩니다. 주민등록번호 등 원본 인사카드를 조회하는 관리 권한은 제공하지 않습니다.
- 직원 비밀번호 초기화 후에는 전달받은 임시 비밀번호로 로그인하고 새 비밀번호로 변경해야 합니다.
- 직원 삭제 메뉴마다 업무 기록 삭제 범위가 다를 수 있습니다. 발행 공문·증명서는 서류 발급 메뉴의 별도 삭제 절차로 관리합니다.

### 확인할 사항

- 민감정보는 업무에 필요한 범위에서 입력하고 접근 가능한 관리자를 확인하세요. 현재 인사카드에 별도 주민번호 마스킹·필드 암호화 기능이 제공된다는 뜻은 아닙니다.

## 5. 대시보드·근태 기록·연차휴가

대상: 모든 회사 구성원

본인의 출퇴근과 신청 내역을 확인하고, 관리자 권한에 따라 회사 또는 본부 현황을 조회합니다.

### 처리 순서

1. 대시보드의 근태 기록에서 출근·퇴근을 등록하고 타임라인에 반영된 시각을 확인합니다.
2. 월별 근태 달력에서 해당 월의 기록을 조회합니다. 관리자는 허용된 직원 범위 안에서 대상자를 선택합니다.
3. 연차·휴가 화면에서 잔여 일수와 입사일 기준 산정 결과를 확인합니다.
4. 연차·반차 등 휴가 종류, 기간과 사유를 입력하고 필요한 증빙을 첨부해 신청합니다.
5. 본인 신청 목록에서 대기·승인·반려 상태와 결재 결과를 확인합니다.

### 기능과 권한

- 사용 연차에는 최종 승인된 연차·반차가 반영됩니다. 신청 대기 상태와 최종 승인 상태를 구분해 확인하세요.
- 대시보드의 내 발급 서류는 발행일 기준 최근 30일을 기본 표시하며, 시작일·종료일을 지정해 이전 PDF를 찾을 수 있습니다.
- 근태 카드와 달력은 작은 세로 여백으로 표시되며, 작은 화면에서는 카드가 세로로 배치됩니다.

## 6. 결재/승인 관리·지출결의 조회

대상: 신청자 · 부관리자 · 회사 관리자

휴가·지출의 신속 결재와 서류의 순차 결재를 구분하고, 본인 또는 회사의 처리 내역을 조회합니다.

### 처리 순서

1. 직원은 휴가 또는 지출결의를 작성합니다. 지출은 일자·금액·분류·사유를 입력하고 영수증을 첨부합니다.
2. 부관리자는 결재/승인 관리에서 소속 본부의 신청을 검토해 1차 승인하거나 반려합니다.
3. 회사 관리자는 최종 승인합니다. 휴가·지출은 1차 승인이 없어도 직접 최종 승인할 수 있습니다.
4. 신청자는 본인의 내역에서 처리 상태를 확인합니다. 관리자 본인 신청도 휴가·지출은 별도 승인 작업이 필요합니다.
5. 회사 관리자는 지출결의 조회에서 기간별 승인 총액과 일자별·대상별 내역을 확인하고 CSV 내역 또는 영수증 ZIP을 다운로드합니다.

### 기능과 권한

- 결재함의 서류 결재 (N)는 열람 가능한 서류 중 결재 대기 상태의 전체 건수입니다. 현재 내 차례인 문서만 센 값은 아닙니다.
- 공문·증명서는 문서에 설정된 중간 결재 순서를 완료한 뒤 최종 승인합니다. 관리자는 결재라인을 변경하거나 중간 결재자를 생략할 수 있으며, 관리자 본인 서류 제출은 자동 승인됩니다.
- 부관리자는 본부 배정이 있어야 다른 직원의 본부 신청을 관리할 수 있습니다. 관리자의 회사 지출 통계 메뉴와 부관리자의 결재함 조회는 범위가 다릅니다.
- CSV는 표 계산 프로그램에서 열 수 있는 내역 파일이고, ZIP은 권한이 있는 승인 지출의 영수증을 묶은 파일입니다.

## 7. 공지 게시판: 작성·수정·삭제

대상: 모든 회사 구성원 · 작성은 관리자/부관리자

구성원은 공지를 조회하며, 관리자는 회사 공지와 첨부자료를 관리합니다.

### 처리 순서

1. 공지 게시판에서 제목이나 내용을 검색하고 게시글을 펼쳐 읽습니다.
2. 회사 관리자와 부관리자는 제목·분류·내용을 입력하고 필요한 자료를 첨부해 공지를 등록합니다.
3. 작성자는 본인이 작성한 게시글을 수정합니다. 회사 관리자는 회사 게시글 전체를 수정할 수 있습니다.
4. 게시글 삭제가 필요하면 회사 관리자가 확인 후 삭제합니다. 첨부 다운로드도 같은 회사의 접근 권한을 확인합니다.

### 기능과 권한

- 현재 서버 권한에서 부관리자의 본인 글 삭제는 허용하지 않습니다. 부관리자는 본인 글을 수정하고 삭제는 회사 관리자에게 요청합니다.

## 8. 급여 관리: 월별 급여대장·연간 급여명세서

대상: 회사 대표 가입자 · 회사 관리자

급여·공제 설정으로 예상액을 검토하고 회사 전체 월 급여를 확정합니다. 확정한 직원별 상세 내역을 서버에 저장하며, 저장된 값으로 월별 급여대장과 직원별 연간 급여명세서 PDF를 생성합니다.

### 처리 순서

1. 대상 연도·월을 선택하고 직원의 연봉 또는 월급 입력 방식을 정합니다. 월급 입력도 연 환산액으로 저장하며, 월 지급액은 항상 저장 연봉의 12분의 1로 계산합니다.
2. 본인 포함 공제대상 가족 수, 공제대상 8~20세 자녀 수와 월 비과세액을 확인하고 직원별 설정 저장을 누릅니다. 이전 급여 설정 경고가 있으면 금액을 검토한 뒤 저장합니다.
3. 본부·팀·이름으로 조회한 목록의 예상 합계와 소득세·지방소득세·보험 공제 상세를 확인합니다. 조회 필터는 회사 전체 급여 확정 대상에 영향을 주지 않습니다.
4. 회사 전체 급여 확정을 누르고 서버에서 확인한 전체 인원·0원 급여 인원·지급액·공제액·실지급액·세액표 출처를 검토해 승인합니다. 저장하지 않은 설정이 있으면 먼저 저장해야 합니다.
5. 확정 완료 후 월별 급여대장 PDF를 다운로드해 외부 PDF 프로그램에서 인쇄합니다. 확정된 상세 급여대장은 수정·삭제할 수 없습니다.
6. 대상 연도와 직원을 선택해 연간 급여명세서 PDF를 생성합니다. 퇴사자도 선택할 수 있으며 해당 연도의 저장된 월별 확정액만 집계합니다.
7. 과거 승인 내역에서 시작월·종료월을 지정해 조회하고 월별 PDF를 다운로드합니다. 직원별 상세자료가 없는 이전 집계 기록은 상세내역 없음으로 표시하며 해당 이전 기록만 삭제할 수 있습니다.

### 기능과 권한

- 퇴직급여는 월 급여에 포함하지 않으며 포함·별도 선택과 메일 발송 기능은 제공하지 않습니다. 현재 설정을 바꾸어도 이미 확정된 월별 급여 값은 바뀌지 않습니다.
- 플랫폼 운영자가 등록한 전체 세액표를 검증해 적용합니다. 등록표에 오류가 있으면 오류 사유와 공식 기본표 대체 출처를 표시하고 표 전체를 대체합니다. 등록 파일명·등록일·적용일과 고소득 급여 기준세액의 출처도 확인할 수 있습니다.
- 기본 근로소득 간이세액표는 2026년 3월 적용 기준입니다. 선택한 월에 따라 2026년 7월 국민연금 상·하한 변경을 반영하고 소득세·지방소득세는 10원 미만을 버립니다. 현재 확정 지원 기간은 2026년 3~12월이며 다른 기간의 기존 승인 PDF 조회는 가능합니다.
- 연간 명세서에서 상세 확정 자료가 없는 월은 미확정 또는 이전 집계로 표시합니다. 현재 급여 설정을 과거 월에 복사해 금액을 채우지 않으며 확정 자료가 있는 월만 합산합니다.

### 확인할 사항

- 화면의 산출액은 현재 설정의 예상액이며, 확정 문서는 승인 시 저장된 설정을 기준으로 합니다. 입퇴사 월의 일할 계산, 보험 가입 예외, 원천징수 80%·120% 선택과 연말정산은 자동 처리하지 않으므로 확정 전에 별도로 검토하세요.

## 9. 서류 발급: 공문·재직·경력증명서

대상: 모든 회사 구성원 · 템플릿/삭제는 회사 관리자

세 종류의 서류가 회사 기본정보와 문서번호를 함께 사용하며, 승인된 PDF를 서버에 보관해 다운로드합니다.

### 처리 순서

1. 회사 관리자가 회사명·주소·대표자·로고·인감을 입력하고 인감 가로·세로 mm 크기와 마지막 발행 순번을 저장합니다.
2. 신청자는 공문·재직증명서·경력증명서 종류를 선택하고 내용을 작성해 초안을 저장한 뒤 제출합니다.
3. 지정된 결재자가 순서대로 승인한 뒤 회사 관리자 또는 위임된 본부 부관리자가 최종 승인합니다. 회사 관리자가 본인 서류를 제출하면 즉시 승인·발급됩니다.
4. 승인 PDF는 비공개 서버 저장본으로 보관합니다. 신청자는 대시보드, 권한 있는 담당자와 관리자는 서류함에서 PDF를 다운로드해 외부 프로그램으로 인쇄합니다.
5. 발행본 수정은 회사 관리자가 수행하고 이전 내용을 보관합니다. 수정본도 다시 제출·승인해야 새 PDF를 발급합니다.
6. 발급 문서 삭제는 회사 관리자가 경고와 비밀번호 재확인을 거쳐 진행합니다. 처리 중 오류가 나면 삭제 다시 시도를 사용합니다.

### 기능과 권한

- 문서번호 예시는 001-261105입니다. 앞 세 자리만 발행마다 증가하고 뒤 여섯 자리는 한국 발행일 YYMMDD입니다. 최초 기준값과 최종 승인 때의 수동 번호는 회사 관리자가 관리합니다.
- 회사 관리자 서류함은 최종 수정일 기준 최근 30일이 기본이며 기간 조회가 가능합니다. 대시보드의 본인 발급내역은 발행일 기준 최근 30일입니다.
- 로고·인감은 파일당 3MB 이하 PNG/JPEG를 등록합니다. 인감은 5~50mm 범위에서 0.1mm 단위로 지정하며 발행 PDF에 반영합니다.
- 프린터 등록·점검과 시험인쇄 메뉴는 제공하지 않습니다. 설정한 PDF 인감 크기를 출력에 반영하려면 외부 프로그램에서 실제 크기(100%)로 인쇄하고 출력 결과를 확인하세요.
- 삭제하면 현재 내용·수정 이력·관련 PDF·알림을 제거합니다. 발행번호는 재사용하지 않으며 이미 외부에 다운로드한 사본에는 영향을 주지 않습니다.

## 10. 기안 작성과 일일·주간 업무보고

대상: 모든 회사 구성원 · 결재/확인은 조직도에서 지정한 책임자

지출결의 신청 바로 위의 기안(업무보고) 메뉴에서 기안서 작성·일일업무보고·주간업무보고를 선택합니다. 회사 서류 결재함과 대시보드의 발급 내역에서 함께 확인합니다.

### 처리 순서

1. 작성자의 본부와 팀 배정을 확인한 뒤 기안 제목·내용·참조 요청사항을 입력하고 견적서 등 첨부자료를 선택합니다. PDF·PNG·JPEG·WebP·GIF 파일을 파일당 10MB, 최대 5개·합계 30MB까지 첨부할 수 있습니다.
2. 팀장, 소속 본부장, 협조가 필요한 다른 본부의 본부장, 대표 중 필요한 결재 단계를 선택합니다. 결재자는 조직도에 실제 임명된 활성 계정에서 정합니다.
3. 본부장 전결은 팀장 → 협조본부장 → 소속 본부장 순서이고, 대표 결재는 팀장 → 소속 본부장 → 협조본부장 → 대표 순서입니다. 협조가 없거나 팀장 단계를 선택하지 않으면 해당 단계를 제외합니다.
4. 최초 저장하면 한국 현재 날짜와 본부·연월별 순번이 확정됩니다. 예: 전략기획본부 11월 세 번째 기안은 전략기획 11-003입니다.
5. 결재 요청 후 지정된 결재자가 자기 차례에 승인하거나 사유를 입력해 반려합니다. 관리자도 선택된 결재선의 현재 차례가 있어야 승인할 수 있습니다.
6. 마지막 결재자가 승인하면 첨부파일 목록이 포함된 PDF를 서버에 비공개 저장합니다. 기안서와 대시보드에서 다운로드해 외부 PDF 프로그램으로 출력합니다. 견적서 등 첨부 원본은 기안서의 첨부자료에서 별도 다운로드합니다.
7. 일일업무보고는 하루, 주간업무보고는 1~7일의 보고기간과 업무 내용을 입력합니다. 제목은 일일 업무보고 또는 주간 업무보고로 고정하며 문서번호는 부여하지 않습니다.
8. 업무보고의 확인자는 조직도에 임명된 작성자 소속 팀장 → 본부장으로 자동 지정됩니다. 두 책임자가 확인하면 동일한 양식의 업무보고 PDF를 다운로드할 수 있습니다.

### 기능과 권한

- 기안일과 번호는 최초 저장 후 유지됩니다. 다음 달에는 새 월 순번이 001부터 시작하며, 연도와 본부 식별자를 별도로 관리합니다. 개정이나 삭제로 이미 부여한 번호를 재사용하지 않습니다.
- 참조는 선택한 협조 본부장으로 자동 기록됩니다. PDF 우측 상단에는 담당자와 실제 승인자의 직책·이름·승인 시각을 표시합니다. 관리자가 대신 제출하면 대리 제출자도 기록합니다.
- 겸직자는 마지막으로 선택된 책임 단계에서 한 번만 결재하며 직책을 함께 표시합니다. 본인이 조직 책임자인 경우도 제출과 별도로 명시적인 결재가 필요합니다.
- 관리자의 결재/승인 관리함 → 서류 결재에 통합됩니다. 관리함 접근 권한이 없는 직원 결재자는 기안서 메뉴나 본인 알림에서 지정 문서를 처리합니다.
- 내용·결재선을 변경하면 이전 내용을 보관하고 승인을 초기화해 재결재합니다. 발행 후 수정·이력 삭제는 회사 관리자가 관리하며, 발행본 삭제는 경고와 비밀번호 재확인을 거칩니다.
- 모든 작성자는 최종 수정일 기준의 시작일·종료일을 지정해 조회할 수 있습니다. 기본 조회는 최근 30일이며, 업무보고 탭마다 해당 종류를 표시합니다.
- 회사 대표자(SUPER_ADMIN)와 ADMIN은 회사 전체 업무보고를 언제든지 열람합니다. 그 밖의 구성원은 본인 작성 또는 지정된 결재/확인 문서만 조회하며, 관리자도 지정되지 않은 확인 순서를 건너뛸 수 없습니다.

### 확인할 사항

- 양식의 보존년한 3년은 문서에 표시하는 값이며 자동 삭제 일정이 아닙니다. 기안서는 회사 인감 등록 없이 사용할 수 있고 기존 공문·증명서의 관리자 자동승인 규칙은 적용하지 않습니다.

## 11. 시스템 설정과 안전한 업무 운영

대상: 회사 관리자 · 모든 사용자

회사별 접근 범위와 계정 상태를 확인하고 도메인·문서·비밀번호 설정을 관리합니다.

### 처리 순서

1. 관리자는 시스템 설정에서 회사 도메인과 관리자 보안 설정을 확인합니다.
2. 구성원은 로그인 주소를 확인하고 최초 비밀번호 변경을 완료한 뒤 업무를 시작합니다.
3. 입·퇴사나 소속 변경 시 관리자는 직원의 역할·본부·팀·계정 상태를 함께 확인합니다.
4. 인사카드·급여·첨부·서류는 허용된 역할과 회사 범위 안에서 사용하고 다운로드 파일의 보관 대상을 정합니다.
5. 중요한 설정·계정·서류 삭제에는 관리자 본인 비밀번호를 다시 확인하고 처리 결과를 확인합니다.

### 기능과 권한

- 회사 식별자, 현재 계정 상태와 권한을 서버에서 확인합니다. 회사별 접근 제어와 비공개 파일 저장을 사용하며 회사마다 별도 물리 서버가 있다는 뜻은 아닙니다.
- 최초 비밀번호 미변경, 퇴사·업무정지 또는 회사 이용 상태에 따라 업무 접근이 제한될 수 있습니다.
- 서류 내용·회사 인감의 공개 URL을 제공하지 않으며, 문서 접근과 PDF 다운로드 때 권한과 현재 승인 상태를 확인합니다.

## 이용 전 확인사항

- 화면의 역할 표시와 회사별 관리 범위를 함께 확인하세요. 회사 대표와 추가 관리자는 소속 회사를 관리하며 플랫폼 운영자와 구분됩니다.
- 휴가·지출의 직접 최종 승인과 공문·증명서의 순차 결재는 서로 다른 절차입니다.
- 기안서는 선택 결재선의 마지막 승인으로 발급되며, 관리자 자동승인이나 일반 서류의 최종 승인 위임 규칙을 사용하지 않습니다.
- 급여는 예상 계산 결과입니다. 기본 세액표 적용일과 별개로 보험 기준·대상 연월을 확인해야 합니다.
