# ERP 창고 간 이동

## 사용 순서

1. 회사 관리자 계정으로 로그인하여 ERP → **창고 이동**을 연다.
2. 출발 창고로 `기초재고 통합` 등 실제 재고가 있는 창고를 선택한다.
3. 본사·연구소·상품구성 등 도착 창고를 선택한다. 회사별 활성 창고 중 최대 5곳을 화면에서 동시에 선택할 수 있다.
4. 이동일과 3자 이상의 사유를 입력하고 **출발 재고 불러오기**를 누른다.
5. 각 품목의 도착 창고별 수량을 입력한다. 빈칸·0은 이동 대상에서 제외되며 소수점 4자리까지 지원한다. 재고 새로고침은 입력 수량을 초기화한다.
6. **창고 이동 미리보기**에서 모든 출발·도착 수량과 재고금액을 확인한다. 확인란을 선택하고 **창고 이동 확정**을 누른다.
7. 입출고 총괄·원장에서 이동입고·이동출고를 조회하고 Excel로 내려받는다. 상세 원장에는 상대 창고가 표시된다.

한 번에 품목·도착 창고 조합 75개까지 처리한다. 예를 들어 24개 품목을 3곳에 배분하면 72개 조합이다. 수량만 등록을 보류한 품목은 이동할 현재고가 없으므로 표시되지 않는다. 창고 또는 품목이 없으면 해당 회사의 기준정보 관리에서 먼저 등록한다.

## 재고와 금액 처리

- 회사 관리자만 미리보기·확정·출발 현재고 조회를 실행한다. 서버에서 로그인 사용자, 회사, 활성 상태와 세션을 다시 검사한다.
- 모든 출발·도착 재고와 원장, 처리 문서, 감사 기록을 하나의 Firestore 트랜잭션으로 반영한다. 일부 품목에 오류가 있으면 전체 처리가 중단된다.
- 출발 창고의 이동평균 원가로 품목별 총 이동금액을 한 번 계산한 다음 도착 창고별 수량에 비례하여 원 단위로 배분한다. 전량 이동 시 출발 잔액은 0원이다. 총수량·총재고금액은 보존되고 매출·매입은 발생하지 않는다.
- 재고 부족, 중지된 품목·창고, 동일 출발·도착, 중복 배분을 거부한다. 날짜는 기초재고 기준일 다음 날 이후이면서 마지막 거래일보다 빠를 수 없다.
- 미리보기 이후 재고·기준정보·원장이 바뀌면 확정을 차단하고 새 미리보기를 요구한다. 같은 확정 요청의 재전송은 중복 반영하지 않는다.
- 입출고 총괄의 공식은 `기초 + 입고 - 출고 + 이동입고 - 이동출고 + 조정 = 기말`이다. 수량 전용 사용자의 화면·Excel에는 이동 원가를 포함한 금액을 제공하지 않는다.

## 취소

상세 원장에서 이동 행의 **문서 취소**를 선택하면 해당 배분 전체의 역거래를 추가한다. 기존 원장은 보존한다. 관련 품목·창고에 후속 거래가 있으면 전체 취소를 차단한다. 이동 입고 행만 매입반품하거나 이동 출고 행만 판매반품할 수는 없다.

## 구현과 배포 범위

- 기존 `manageErpCorrection`에 `TRANSFER`와 `transferStock`을 추가하고 `manageErpReport`를 확장한다.
- 기존 회사 하위 ERP 컬렉션과 접근 규칙을 사용한다. 새 컬렉션·권한 완화·데이터 이관은 필요하지 않다.
- 웹은 `jwmaxum/hr-flow`의 main → Cloudflare Pages `hr-flow` → `https://hr-flow-chj.pages.dev/`로 배포한다.
- Firebase는 `weberp-8f25f`의 `manageErpCorrection`, `manageErpReport`만 배포한다. Firebase Hosting은 배포하지 않는다.
- 배포 자체는 실제 회사의 재고를 이동시키지 않는다. 회사별 실제 배분 수량을 입력한 뒤 확정한다.

## 검증

`functions/tests/erp-ledger.test.js`에서 여러 품목·창고 배분, 반올림과 전량 이동, 기존 도착 재고 원가, 중복 확정, 동시 요청, 오래된 미리보기, 잘못된 입력, 권한·회사 격리, 전체 취소와 후속 거래 차단을 검증한다. `client/e2e/smoke.spec.cjs`의 창고 이동 시나리오는 데스크톱·모바일에서 입력·미리보기 무효화·확정·원장·취소를 합성 회사로 확인한다. `client/tests/erp-workbook.test.mjs`는 이동 수량·금액의 Excel 열과 수량 전용 접근을 검증한다.

다음 개발 단계는 원가 미확정 품목의 보완 입력과 실제 보관 장소별 실사 대사를 연결하는 것이다.
