# ERP관리자 전체 권한과 주요 변경 점검

기준일: 2026-11-15

## 권한

ADMIN은 기존과 같이 ERP 전체 업무를 처리합니다. SUB_ADMIN 직원에게 별도의 ERP 담당 업무 **ERP관리자(MANAGER)** 옵션을 지정하면 ADMIN 승인 없이 입고·출고, 수량·금액 조정, 취소·반품, 수금·배분·반환, 거래명세표 발행·정정, 승인 요청 처리, 월마감 확정·재개방, 마감 계획·체크리스트와 ERP 담당자 권한 관리를 할 수 있습니다.

ERP관리자 옵션은 일반 직원에게 지정할 수 없으며, 자신의 권한 변경도 허용하지 않습니다. 이 옵션은 HR의 ADMIN 권한으로 승격시키지 않습니다. 회사별 데이터 분리와 비활성 계정 차단, 월마감 잠금은 유지합니다. 마감된 기간의 거래는 재개방 절차 이후 수정합니다. 마감 계획의 담당 항목 제출은 배정 담당자가 수행하고 관리자는 검토·체크리스트·마감을 처리합니다.

다른 입고·출고 담당자의 수정·삭제 요청은 기존 승인 절차를 유지하며, ADMIN 또는 ERP관리자가 승인할 수 있습니다. 확정 거래와 발행 서류는 이력을 지우는 삭제 대신 취소·정정 기록을 남깁니다.

## ADMIN 확인 방법

1. ERP → 대시보드 → **주요 변경 점검**을 엽니다.
2. 조회 기간과 변경 유형을 선택합니다. 기본 기간은 대시보드의 선택 월이며, 처리 시각의 한국 날짜를 기준으로 조회합니다. 거래 기준일과 처리일은 다를 수 있습니다.
3. 재고 변동, 거래 수정·정산, 취소·삭제·사용중지, 거래서류 변경, 월마감·승인, 기준정보·권한별 건수를 확인합니다.
4. 표에서 담당자, 처리 시각, 사유, 문서번호, 직접 처리·승인 구분을 확인하고 상세를 펼쳐 변경 전후 값을 비교합니다. 거래서류에는 수량·단가·공급가액·부가세·합계도 표시됩니다.
5. 전체 이력 버튼으로 원본 변경 기록을 확인합니다.

한 작업의 분할 이력은 한 건으로 계산합니다. 한 작업이 여러 유형에 포함될 수 있어 유형별 건수의 합이 전체 건수보다 클 수 있습니다. 한 번에 93일 이내를 조회하며, 1,000개 이력 또는 20MiB를 넘으면 기간을 좁히도록 안내합니다. 일부만 합산하지 않습니다. 화면은 30건씩 조회하며 상세는 앞 40개 변경 기록, 문서는 앞 20개 변경 행을 표시합니다. 전체 원본은 변경 이력에 보관됩니다.

## 반품 후 조회 장애 복구

반품이 확정되었지만 목록 조회에 실패하면 **처리는 완료되었습니다** 안내와 **반영 결과 다시 조회** 버튼을 표시합니다. 버튼은 이미 확정된 결과만 다시 조회하며 반품을 재등록하지 않습니다. 조회 성공 시 미수금·반환 예정액을 확인하고 거래명세표 정정 화면으로 이어집니다. 원본 문서는 보관하고 취소·정정 초안을 거쳐 새 PDF를 발행합니다.
